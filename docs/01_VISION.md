# Why ModeAlert Exists

Gamers constantly miss important events.

Limited-time skins.

Battle Pass deadlines.

Ranked split endings.

Champion rotations.

Prime Gaming rewards.

Free champions.

Drops.

Store updates.

Patch releases.

Tournaments.

Community events.

Players are forced to constantly check:

- Game Client
- Twitter/X
- Reddit
- Discord
- Riot News
- CommunityDragon
- Patch Notes
- Third-party websites

ModeAlert eliminates that problem.

---

# Mission

Deliver the right information to the right player at the right time.

Never spam.

Never overwhelm.

Never require manual checking.

---

# Vision

Become the notification platform for gaming.

Players should think:

"I don't need to check anything anymore.
ModeAlert will tell me."

# Core Principles

Every feature should satisfy at least one of these:

Increase value.

Reduce maintenance.

Increase automation.

Increase scalability.

Improve user experience.

Generate revenue.

If a feature does none of these,
it probably should not exist.
