# ModeAlert Documentation

Welcome to the ModeAlert documentation.

This directory contains the project's architectural decisions, development philosophy, business vision and long-term roadmap.

The documentation is considered part of the project itself.

If code changes but documentation does not, the work is considered incomplete.

# Documentation Philosophy

ModeAlert is designed to be maintained for years.

This documentation exists so that:

- architecture decisions are never forgotten
- new contributors can understand the project quickly
- future refactors preserve the original vision
- AI assistants can immediately understand the system
- technical debt is minimized

Documentation is never considered optional.

---

# Documentation Rules

Every significant change should update one or more documents.

Examples:

New provider
→ Architecture
→ Decisions

Database changes
→ Architecture
→ Database section (future)

New revenue model
→ Business Model

New long-term feature
→ Roadmap
→ Backlog

Architectural change
→ Decisions
